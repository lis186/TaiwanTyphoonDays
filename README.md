# TaiwanTyphoonDays

紀錄臺灣歷次「天然災害停止上班上課」（俗稱颱風假）的 JSON 資料，內容包含日期、縣市、子區域、停止上班／上課情形與時段。

姊妹專案：[TaiwanCalendar](https://github.com/ruyut/TaiwanCalendar)（政府行政機關辦公日曆表）。

## 關於

資料來源為行政院人事行政總處（DGPA）的[歷次天然災害停止上班上課訊息](https://www.dgpa.gov.tw/informationlist?uid=374)。
該頁面只提供 HTML 公告，且各年代格式不一，直接使用有下列困難：

* 每次事件的內容放在附件 HTML，不在公告頁本身
* 2001 年起至今格式至少有三種（Big5／UTF-8、「辦公」／「上班」、縣市改制後名稱變動）
* 狀況是自由文字（「今天下午01:00起停止上班、停止上課」），需自行解析
* 106 年起每則公告同時含「今天」與「明天」的狀況

故將資料整理成結構化 JSON，並保留原文供回查。

目前收錄 **503 個事件日，2001-07-30 ～ 2026-10-24**。

## 資料檔

```
data/{西元年}.json
```

每個檔案是依日期排序的陣列，一個事件日一筆。

## 資料格式

```json
{
  "date": "20261023",
  "publishedAt": "20261027",
  "updatedAt": "2026-10-23T20:21:50",
  "sourceUrl": "https://www.dgpa.gov.tw/information?uid=374&pid=13129",
  "parsed": true,
  "areas": [
    {
      "city": "高雄市",
      "scope": "旗山區",
      "forDate": "20261023",
      "work": "stop",
      "school": "stop",
      "period": "from",
      "from": "12:00",
      "raw": "旗山區:今天中午12:00起停止上班、停止上課。"
    }
  ]
}
```

### 事件欄位

| 欄位 | 說明 |
|---|---|
| `date` | 事件日（取自公告標題，不是公告日），格式 `YYYYMMDD` |
| `publishedAt` | 公告日，常比事件日晚 1～3 天 |
| `updatedAt` | 附件內標示的更新時間；舊資料沒有則為空字串 |
| `sourceUrl` | 原始公告頁 |
| `parsed` | `false` 表示只有 `raw`，沒有結構化結果（見下） |
| `areas` | 各縣市／子區域的狀況，見下表 |

### `areas` 欄位

| 欄位 | 值 |
|---|---|
| `city` | 縣市名（只統一字形：台→臺、巿→市） |
| `scope` | 子區域（鄉鎮、村里、學校名等）；空字串表示整個縣市 |
| `forDate` | 這筆記錄實際適用的日期 `YYYYMMDD` |
| `work` | `stop`（停止上班）｜`normal`（照常上班）｜`null`（未解析） |
| `school` | `stop`｜`normal`｜`partial`（僅部分學制停課，如「高中及高中以下停止上課」）｜`null` |
| `period` | `allDay`｜`morning`｜`afternoon`｜`evening`｜`from`（自某時刻起）｜`null` |
| `from` | `period` 為 `from` 時的 `HH:MM`（24 小時制），否則為空字串 |
| `raw` | 該句原文，一律保留 |

### 使用上的注意事項

**`forDate`：每則公告同時含「今天」與「明天」。** 106 年起，事件日 D 的公告可能寫「明天停止上班」，此時該筆記錄的 `forDate` 為 D+1。要查「某天有沒有停班」：

1. 取所有 `forDate` 等於該日的記錄。
2. 若同時存在該日自己的公告（`date` 等於該日）與前一天公告的「明天」預告，**以該日自己的公告為準**。
3. 有 4 天只出現在前一天公告的「明天」中，沒有自己的公告頁（2022-10-17、2024-08-09、2024-11-06、2025-06-14），所以不能只讀 `date` 等於該日的事件。

**「已達停止標準」與「停止」視為同義。** 「今天已達停止上班及上課標準」記為 `stop`，「未達」記為 `normal`；兩種措辭是不同年代或不同縣市的用詞，差異只保留在 `raw`。

**複合句會拆成多筆。** 「上午已達、下午未達」會拆成兩筆（`morning`／`afternoon`）；同一格內有多個子區域也各拆一筆。

**縣市名保留當時名稱，不對應現行行政區。** 2010 年前的臺北縣、臺中縣、臺南縣、高雄縣與 2014 年前的桃園縣，在改制前後無法一對一對應，故不合併。

**保留所有公布的列，包含「照常」的縣市。** 早期公告列滿所有縣市，106 年起只列有狀況的縣市；本專案不替使用者過濾。

## 已知問題

* **102 年有 24 個事件無附件**，內容是高雄市桃源區、那瑪夏區個別學校的自由文字（標點與措辭不一致）。這些事件 `parsed` 為 `false`，`areas` 只有一筆，僅 `city` 與 `raw` 有值。
* **有 28 個句子（共 19 種寫法）未解析**，分布在 14 個已解析的事件中。這些記錄的 `work`／`school`／`period` 為 `null`，請讀 `raw`。內容多為括號備註、「晚上6:00前停止」、以及擠在同一格而沒有分隔的學校清單。這些句子零碎，刻意不為它們增加規則，以免誤判。
* **「尚未列入警戒區」「尚未宣布消息」共 524 句未收錄**，因為不含停班資訊。若某個事件整份都是這類句子，則 `areas` 為空陣列、`parsed` 為 `true`。
* 原始公告是各縣市政府通報的彙整，內容以各縣市政府實際發布為準。

## 更新資料

需求：Python 3（僅用標準函式庫）。於專案根目錄執行：

```
python3 scripts/crawl_list.py   # 爬列表，產生 .cache/all_items.json
python3 scripts/fetch_all.py    # 抓內頁與附件到 .cache/（已存在的不重抓）
python3 scripts/parse.py        # 產生 data/{year}.json，加 --report 列出未解析的句子
```

`.cache/` 為原始 HTML 快取，不納入版控。
